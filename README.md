# Math Solver Bot

A Telegram bot that solves mathematical problems using Python.

## Features

*  Basic calculations
* Addition, subtraction, multiplication, division
* Power calculations
* Square root calculations
* Algebraic expressions
* Equation solving

## Technologies

* Python 
* python-telegram-bot
* SymPy

## Examples

Input:

```
5+10
```

Output:

```
15
```

Input:

```
2^10
```

Output:

```
1024
```

Input:

```
sqrt(144)
```

Output:

```
12
```

Input:

```
x^2-9=0
```

Output:

```
[-3, 3]
```

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/MathSolver.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python bot.py
```

When the bot starts successfully:

```
🧮 Math Solver Bot Running...
```

## Requirements

```
python-telegram-bot==22.0
sympy==1.13.3
```
